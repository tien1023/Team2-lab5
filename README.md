# ECE 2161 Lab 5: Running Time of Sorting Algorithms
by Tien Tran, Gilbert Argueta and Vivianna Grande

## Overview
This project implements six different sorting algorithms (Bubble Sort,
Shell Sort, Insertion Sort, Heap Sort, Selection Sort, and Radix Sort) to be used on large sets of inteagers.
Each algorithm can be tested on two datasets: the first consisting of 1,000,000
integers, and the second consisting of 2,000,000. When the program starts,
the user is given a menu to (1) Read Data from a user-selected Small or Large Input File,
(2-7) Sort the Data using the various sorting algorithms, or (0) Exit the
Program. After an algorithm is run, the sorted dataset is written into its respective
output text file. The program ends once the user exits the program, or closes the window its running in.
